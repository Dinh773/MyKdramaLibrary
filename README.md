# 🎬 My K-Drama Library

Une application web Fullstack (MERN) moderne et réactive permettant de découvrir des séries coréennes (K-Dramas), de consulter leurs détails et de gérer une liste de visionnage personnelle (Watchlist).

---

## 🚀 Démo en ligne

- **Frontend (Vercel) :** [https://votre-app.vercel.app](https://votre-app.vercel.app)
- **Backend API (Render) :** [https://votre-backend.onrender.com](https://votre-backend.onrender.com)

---

## ✨ Fonctionnalités

- 🔍 **Recherche en temps réel :** Trouvez instantanément vos K-Dramas favoris via l'API TMDB.
- ⚡ **Filtres dynamiques :** Tri par popularité, note ou date de sortie.
- 📑 **Navigation par onglets :** Basculez facilement entre la découverte de séries et votre Watchlist.
- 📌 **Gestion de Watchlist :** Ajoutez ou retirez des séries enregistrées de manière persistante sur MongoDB.
- 📱 **Design réactif :** Optimisé pour ordinateurs portables, tablettes et smartphones.

---

## 🛠️ Technologies utilisées

### Frontend
- **React 18** (avec Vite)
- **CSS3 moderne** (Variables CSS, Grid, Flexbox)
- Déploiement : **Vercel**

### Backend
- **Node.js** & **Express**
- **MongoDB Atlas** & **Mongoose** (Gestion de la base de données)
- **Axios** / **Node-Fetch** (Proxy pour sécuriser les requêtes vers l'API TMDB)
- Déploiement : **Render**
